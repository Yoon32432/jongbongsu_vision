# 종량제봉투 인식 시스템 설계 (YOLO + RealSense)

- Status: Approved
- Date: 2026-07-13

## 배경 및 목적

모바일 로봇 + 로봇팔(매니퓰레이터)로 바닥에 놓인 종량제봉투를 픽앤플레이스하는
시스템의 첫 단계로, **인식 파이프라인만** 구축한다. 로봇팔/모바일 베이스 제어는
범위 밖이며, 별도 단계에서 이 모듈의 출력을 소비하는 형태로 통합될 예정이다.

- 대상: 바닥에 단독으로 놓인 종량제봉투 (겹침/더미 없음)
- 카메라: Intel RealSense (RGB + Depth), **그리퍼에 부착(eye-in-hand)** 예정
- 컴퓨팅 환경: 일반 PC/노트북 (GPU 보유)
- 데이터: 공개 데이터셋(AI Hub 등) 우선 조사, 부족 시 직접 촬영·라벨링으로 보강

## 핵심 제약: eye-in-hand의 근접 blind zone

RealSense D4xx 계열은 제조사 스펙상 최소 depth 거리가 약 0.2m대이고, 실무적으로
신뢰할 만한 정확도가 나오는 범위는 대략 0.3m 이상이다. 카메라가 그리퍼에 달려
있으므로, 그리퍼가 봉투에 근접하는 마지막 구간(수 cm~10cm대)에서는 depth를
신뢰할 수 없거나 아예 값이 나오지 않는다.

따라서 이 시스템은 **연속 스트림 소비를 전제하지 않고, "안전거리에서 한 번
안정된 값을 확정(lock-in)해서 내보내는" 방식**으로 설계한다 (look-then-move).
로봇팔 쪽의 좌표 변환(hand-eye calibration, FK 기반 base frame 변환)과
open-loop 최종 접근 실행은 범위 밖이며, 이 모듈은 그 전 단계까지만 책임진다.

## 아키텍처

```
[RealSense D4xx] --RGB+Depth--> [YOLOv8-seg 추론] --mask--> [뎁스 융합 모듈] --> [출력 인터페이스]
                                                                   ^
                                                        [카메라 intrinsics/align]
```

4개 컴포넌트:

1. **데이터 파이프라인**: 학습용 이미지/라벨 확보
2. **모델**: YOLOv8-seg (사전학습 가중치에서 전이학습)
3. **뎁스 융합 모듈**: RGB 인식 결과(마스크)를 뎁스와 정합해 3D 위치/치수 계산,
   유효 거리 필터링 및 다중 프레임 평균으로 안정된 값 확정
4. **출력 인터페이스**: 연속 스트림 API + 단일 캡처(lock-in) API

## 컴포넌트 상세

### 1. 데이터 파이프라인

종량제봉투는 지자체별로 색상/문구/디자인이 달라 일반 재활용품 분류 공개
데이터셋(Kaggle garbage classification 등)은 맞지 않을 가능성이 높다.

- 1순위: AI Hub(aihub.or.kr) 등에서 관련 데이터셋 조사 후 활용 가능하면 활용
- 부족 시: RealSense로 직접 촬영 + 라벨링 (폴리곤 마스크, YOLO-seg 포맷)
  - 소규모(200~500장)로 시작해 파이프라인부터 검증하고, 필요 시 확장
  - 라벨링 도구: Roboflow 또는 CVAT (폴리곤 세그멘테이션 지원)

### 2. 모델

- YOLOv8-seg (Ultralytics), COCO 사전학습 가중치에서 전이학습
- 클래스는 단일 클래스("종량제봉투")로 시작. 종류/용량 구분은 이후 확장 여지로
  남겨둔다 (YAGNI)
- yolov8n-seg 또는 yolov8s-seg 수준이면 일반 PC GPU에서 실시간 추론 가능

### 3. 뎁스 융합 모듈

- `pyrealsense2`로 RGB-D 스트림 획득, `align`으로 depth를 color 프레임에 정합
- YOLO-seg 마스크로 depth 이미지에서 봉투 픽셀만 추출 (배경 바닥 제외)
- 마스크 내 depth 픽셀을 카메라 intrinsics로 3D 포인트로 역투영(deproject)
  → 포인트 클라우드 생성
- 포인트 클라우드에서 중심 위치(centroid, 카메라 좌표계 x/y/z)와 크기/부피
  근사치 계산
- 바닥 평면 노이즈 제거: RANSAC 등으로 바닥 plane을 사전 캘리브레이션해두고
  해당 평면 근방의 depth는 필터링
- **유효 거리 필터**: depth가 신뢰 구간(예: 0.3m ~ 안전거리) 밖이면 값 무시
- **다중 프레임 평균**: 단일 프레임이 아니라 여러 프레임(예: 10~30프레임)을
  평균/필터링해 하나의 안정된 값으로 확정

### 4. 출력 인터페이스

두 가지 API를 제공한다.

- **연속 스트림**: 실시간 디버깅/시각화용. 매 프레임 최신 인식 결과 발행
- **단일 캡처(lock-in)**: `capture_stable_target()` — 신뢰 구간 내에서 다중
  프레임 평균으로 확정된 값을 1회 반환

```
capture_stable_target() -> {
    class, confidence, mask,
    position_xyz,        # 캡처 시점의 카메라 광학 프레임 기준
    size_estimate,
    frame_id, timestamp, # 추후 로봇팔 모듈이 hand-eye calibration + 캡처
                          # 시점의 관절각(FK)으로 base 프레임 변환에 사용
    n_frames_averaged
}
```

로봇팔 모듈은 이 값을 소비해 base 프레임으로 변환 후 open-loop로 최종 접근을
실행하게 되나, 그 좌표 변환/제어 로직은 이 프로젝트의 범위 밖이다.

## 테스트/검증 전략

- **단위 테스트**: 뎁스 융합 모듈은 알려진 크기/거리의 물체(예: 박스)로
  거리·부피 추정 정확도 검증
- **통합 테스트**: 실제 RealSense로 봉투를 여러 거리/각도에 놓고 위치·부피
  추정값을 실측값과 비교
- **반복 정밀도 테스트**: 캡처 안전거리(예: 40~60cm)를 몇 가지로 바꿔가며,
  동일 위치를 반복 캡처했을 때의 확정값 분산을 측정 — 이는 이후 그리퍼 접근
  성공률의 상한을 결정하는 핵심 지표
- **라이브 데모**: 실시간 스트림에서 마스크 오버레이 + 3D 위치 표시로 시각적
  확인

## 범위 밖 (Out of scope)

- 로봇팔/모바일 베이스 제어, hand-eye calibration, 좌표계 변환 실행
- 봉투 종류/용량 세분류
- 다중 봉투 겹침/더미 상황 처리
